# DART

On-demand courier delivery for Rome with driver bidding.

- `website/`: public landing page (EN/IT). Static HTML, no build step. Deploy the folder to any static host (Vercel, Netlify, Cloudflare Pages).
- `mockups/`: first-pass screens for the customer app and courier app.

Next: backend (database, auth, bids, chat, tracking), the two mobile apps, and an admin panel.
